添加 seeinps 运维

代理服务器取自「设置 · 代理服务器」（默认主/备自动回退），此处无需填写。
登录 seeinps 获取
直接填写运维代理
登录成功后先列出该 seeinps 已添加的运维 HTTP 代理，确认名称与目标网段后再生成卡片。连续输错 3 次需验证码，6 次锁定 30 分钟。
已从 获取以下运维代理：名称可改（留空用默认「账号 · 运维ID」）；目标网段按 seeinps 的 ACL 预填，若服务端 ACL 为空或为全网段则必须手动填写。
必填，至少一个网段（决定哪些流量走 VPN，不支持 0.0.0.0/0）
凭「运维ID + 代理账号 + 代理密码」直接生成一张 VPN 卡片，无需登录 seeinps。

手动添加 VPN

未接入 seeinps 管理页时的备选方式：凭「运维ID + 代理账号 + 代理密码」手工填写。
新增的服务器会在点「添加」后一并写入「设置 · 代理服务器」
服务器列表在「设置 · 代理服务器」中维护；指定单台后失败不回退
必填，至少一个网段（决定哪些流量走 VPN，不支持 0.0.0.0/0）

填写代理密码

该运维入口已从 seeinps 同步。出于安全考虑，seeinps 不返回代理密码明文，请向管理员获取后一次性填写（本机 DPAPI 加密保存）。

编辑运维入口

目标网段决定哪些流量走虚拟网卡（对应 seeinps 的 ACL）。
服务器列表在「设置 · 代理服务器」中维护；指定单台后失败不回退
默认仅探测 HTTP 代理是否可用；勾选后额外探测下方内网目标是否可达
应填写一个该内网中稳定可达的 TCP 端口
