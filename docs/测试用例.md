# seeinp 前端测试用例

> 覆盖 seeinpm 中心端、seeinps 服务端、seeinpc 客户端全部功能模块
> 测试方式：手动走查 + 浏览器验证，dev server 运行于 http://localhost:5173/

## 测试环境
- 前端：Vue 3 + Vite dev server（端口 5173）
- 浏览器：Chrome / Edge
- 数据：Mock 数据层（无后端依赖）
- 路由模式：Hash 模式（`#/`），演示模式自动注入登录态

## 测试用例编号规则
- TC-COM-xxx：跨端通用
- TC-PM-xxx：seeinpm 中心端
- TC-PS-xxx：seeinps 服务端
- TC-PC-xxx：seeinpc 客户端

## 优先级定义
- P0：核心功能，阻塞性问题
- P1：重要功能，影响主流程
- P2：一般功能，体验类问题
